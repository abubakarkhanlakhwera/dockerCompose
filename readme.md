# Docker Compose Practice

Practice repository for multi-container Docker Compose workflows.

## Purpose

Applications often need multiple services running together, such as a web app and database. This repo explores how Docker Compose describes and runs those service groups consistently.

## What This Shows

- Multi-container service orchestration
- Compose file concepts
- Development environment setup practice

## Stack

- Docker Compose
- Docker
- EJS/Node practice
